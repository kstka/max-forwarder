# MAX → Telegram Forwarder

Python-скрипт зеркалирует новые сообщения одного канала MAX в Telegram.
Используются Selenium, Chrome и Bot API Telegram; интерфейс MAX работает в
локали `ru-RU`.

## Правила работы

- Канал открывается один раз и наблюдается через live DOM без перезагрузки.
- Приоритет — устойчивость и поведение, похожее на действия человека.
- Настройки хранятся только в локальном `config.py`; он не должен попадать в Git.
- Реальные отправки в Telegram запрещены без явного запроса пользователя.
  Для диагностики используйте `--dry-run` или mock relay.
- Перед обновлением документации обезличивайте все приватные сведения:
  токены, chat ID, ссылки и ID каналов, имена людей, имена и адреса серверов,
  учётные записи, пути рабочей инфраструктуры, содержимое сообщений и журналы.
  Используйте плейсхолдеры вроде `<server>` и `<chat-id>`.
