# Ограничения

- MAX не предоставляет стабильный идентификатор сообщения в DOM. Для защиты
  от дублей используется отпечаток содержимого; у визуально одинаковых
  сообщений он иногда может совпасть.
- Изменение логики извлечения текста или вложений меняет отпечатки. Перед
  развёртыванием таких изменений запускайте `python main.py --once --dry-run`.
- После перезапуска сообщения из уже открытой истории поглощаются в течение
  `STARTUP_GRACE_SECONDS`; пересылаются только новые сообщения после tail anchor.
- Если за один опрос обнаруживается слишком много новых сообщений, burst guard
  помечает их как просмотренные без пересылки. Это защищает чат от массовых
  дублей, но может пропустить настоящий всплеск сообщений.
- Медиа в MAX загружается отложенно. Нераскрытые изображения и очень большие
  файлы могут быть пропущены.
- Видео и аудио пока пересылаются ссылками, а не нативными вложениями Telegram.
- При завершении сессии MAX требуется повторный вход по QR-коду. Автоматическое
  распознавание потери авторизации пока не реализовано.
- `--discover` предназначен для интерактивной диагностики и не подходит для
  запуска без терминала.
